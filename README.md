# 《夜祠》游戏设计方案

**在线阅读（推荐）：** https://gh393872102.github.io/ye-ci/

打开上面的网站可以一页看完全文、画面和进度；以后的更新也会发布到同一地址。下面是仓库目录，方便对照源文件。

**英文名：** Night Shrine  
**版本：** v0.2（2026-11-15）  
**性质：** 可独立上架的纯单机 1.0 制作圣经（GDD）  
**视觉锁定：** 方案 A「墨煞像素」——侧视 2D 实时指挥 + 肉鸽构筑

本文替代 v0.1。v0.1 的 2.5D 仪式动作、俯视镜头，以及「晚在场地上亲自闪避斩击」的方案全部作废。

## 怎么读

按下面的目录顺序往下看即可。每一章末尾有上一章 / 下一章链接。如果你更想一次读完，也可以直接打开 [全文版](docs/夜祠_游戏设计文档_v0.2（全文）.md)。

建议先读第 1–3 章，确认这是一款什么样的成品；再读第 4–9 章，理解三种模式如何共用同一套战场；第 10–13 章是 32 名人物、32 种鬼物和进化装备；第 14–17 章是图鉴、平衡、关卡与操作；第 18–21 章是叙事、美术、范围和验收。
