# P7. 进化、变异与装备

**对应门槛：** 本阶段通过后，即为 **G1 一夜能成**。  
**前置：** P6 通过。局内成长只走本阶段规定的三层，禁止再叠天赋树、宝石盘、宠物栏或第二套卡组。

---

## 1. 本阶段目标

把变异、融契、香器、技艺、名帖做成表驱动且可在一夜中构筑的系统。守香走升级、装香器/技艺/名帖、点职、借神、收编，不走丧尸式变身。夺名走变异（基准四方）和融契。至少三条流派能在一夜内成型并打出对应爽点：优先验收超度流、守门流、破门潮；灯面流、上梁奇袭、无册赌局至少要能露出可玩雏形。

一句话：深度来自标签和构筑，不来自再开一个系统。

## 2. 前置条件

- 必读：GDD 第 8、12、13 章全文，6.4 的变异花费，17 章关于守香不把变异当主指令。
- 表：20 香器、16 技艺、12 名帖的清单以第 12 章为准，必须原样入 `data/items/`，效果按「要点」实现到可感知，不要改名凑数。
- 变异花费初稿：提灯 8，上梁 12，破门 15，融契 20。

## 3. 范围内 / 范围外

**范围内：**

1. 装备槽：每名上场人物或夺名精英可装 1 香器、2 技艺、1 名帖。普通白衣不占格。
2. 20 香器、16 技艺、12 名帖全部入表，并在战斗或一夜中至少能被拿到、装上、产生写在表里的效果。若个别高危件（无册残页、空位神相关）实现不完整，必须在报告列出，且数量不得超过 2 件，其余必须可感知。
3. 变异四方：提灯（白衣/乞名/散香影 → 青灯骨或提灯变体）、上梁（→ 缢鬼）、破门（→ 力士尸）、融契入口。同一单位一夜内不得连变三次。
4. 融契：一夜 1–2 次，必须按配方，不允许纯随机怪胎。第 12.2 节的初稿配方至少实现 3 条（建议：悬线、门骑、以及一条与灯或收编相关的）。结果进图鉴解锁接口。
5. 人类深化：装装备；点职（事件或三选一可让人物多一个标签，先做 1–2 个实例，如铁肩兼一点机关）；借神（花香火和名分请祠神短暂下场，有请到空位神的风险，可用简化演出但规则要在）；收编（超度完成时小概率或用特定香器把鬼转为灰军，可被无册夺回的接口要在，即便无册单位尚未全做）。
6. 三条优先流派的验收局或例夜分支：
   - 超度流：晚、点册、河灯盏或册底针，爽点是精英被超度或收编、名册回亮。
   - 守门流：铁肩、修门/封门、门在最后一下被扛住。
   - 破门潮：力士、开山楔或阴骑（若阴骑未入战斗可用力士+增潮代替并在报告标明），爽点是正门砸开、潮灌入。
7. 另外三条至少各有一条可组成的奖励路径和一次可见特殊反馈（灯揭示、缢鬼上楼、高危借神或残页），完整手感可到 G2 再打磨。
8. 守香升级面板仍不得把变异当作人类主指令。

**范围外：**

- 再加新的成长层。
- 让人物变身成鬼作为默认进化。
- 用「全体 +20% 攻击」这类账号成长冒充深度。

## 4. 详细实现规范

- 所有装备与配方必须能在表里改效果参数。技能脚本按 id 挂接，缺脚本要在启动时报错。
- 技艺「只改一个清楚的行为」。不要把一条技艺写成复合论文。
- 名帖只动属性与抗性，不动规则。规则变化留给香器和科仪。
- 爽点必须有反馈：破门要有碎裂灌入，超度要有送行或给脸的瞬间，门被铁肩扛住要能看出来。没有反馈的数值变化不算打出爽点。
- 调弱某流派时，按 15.4：先改奖励权重和香火曲线，再改单技能参数，最后才改单位定位。
