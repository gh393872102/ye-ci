# P4. 决策指令

**对应门槛：** 本阶段通过后，即为 **G0 规则能玩**。  
**前置：** P3 全部关键项通过。路径时间、潮水、人类 AI 和镜头尺度不得被改坏。

---

## 1. 本阶段目标

把玩家在战斗中真正要做的事做成可用的决策指令，并且守香、夺名都能在第一张验收图上，用指定的六名单位打完一场。玩家通过暂停来购入、部署、升级或变异、点册/超度、修门；单位仍然自动作战。不要做成手拖走位的即时战略，也不要把守香的主指令写成「变异」。

一句话：指令是决策，战场自己在动，两边坐席都能打完。

## 2. 前置条件

- 必读：GDD 第 4、6.2–6.6、12.4、14.1、17 章；杂兵购入数字见第 17 章。
- 标准图 14（购入与部署的信息结构，部署点以 6.6 为准，若图中标记落在院心则改到掩体岗位）、15（升级与装香器，不要把变异当守香主指令）、16（点册过程，施术位置以 6.6 为准）、23（边角警告，门将破 / 名册告急）、25（站位）。
- 六名指定单位：H01 晚、H09 铁肩、H17 朱砂、G01 白衣无面、G09 缢鬼、G12 力士尸。杂兵 T01 乡勇、T02 弩手、T04 更卒按第 17 章费用上场。

## 3. 范围内 / 范围外

**范围内：**

1. 完整的暂停决策循环：Space 暂停 / 继续，1x / 2x，暂停中可打开面板并确认指令。
2. 守香指令：购入、部署到掩体岗位、升级、点册/超度、修门。香器槽可先做「装上一件占位香器」，完整 20 件在 P7。
3. 夺名指令：变异（至少提灯 / 上梁 / 破门三方中的上梁与破门必须能用，提灯如青灯骨未就绪可先留接口但要在报告写明）、增潮（花香火从阴缝补一批白衣，有冷却或次数上限，避免无限刷）、融契可先做接口或一次简化配方，完整配方在 P7。若融契本阶段只留入口，G0 验收以变异和增潮为准，并在报告标明。
4. 部署只能选外门内侧、门厅、窗位、楼梯口、名册房等 `CoverPost`。点在外门以外或庭院中央必须被拒绝并给出提示。
5. 点册 / 超度：由晚（或之后其他守香司）对合法目标读条 3–5 秒，花费 4–6 香火（晚的表定香耗为 4），回报 2–4 香火与 1 名分；中途被打断则亏掉消耗。施术者不得走进院心读条；目标必须已经进入可点册范围（门厅内，或技能说明允许的内侧范围）。其他单位在读条期间继续自动作战。
6. 修门：花香火恢复当前门的耐久，修理者按职分自动靠近门扇内侧作业（榫卯的例外出门外作业留到该单位上场；G0 可用奇人占位或让最近的可修门单位在内侧修）。
7. 升级（守香）：对已选单位花香火提高生命/防御等，预览必须显示当前值与升级后值。不要在这个面板放「变异」。
8. 点击单位：自动暂停并弹出信息面板。P4 必须已经包含完整信息结构（姓名、职分、定位、生命/攻击/防御/速度、技能与消耗、特性、装备槽含空槽、标签）。立绘可用高质量占位，但不得把像素块放大冒充。精绘在 P8/P9 替换。
9. 战斗内警告：门将破、名册告急，贴在边角，不弹全屏挡住战场。见第 23 号图。
10. 资源：开场香火守香 20、夺名 16。香火缓慢自然回复（速率写进 Rules，报告注明）。名分掉到 0 时守香进入「名册将熄」短窗口（时长初稿 8–12 秒，可调），窗口结束仍为 0 则本场失败。
11. 胜负（本场验收规则，先写死在第一张图上，P5 再接到夜程）：
    - 守香胜利：撑到本场倒计时结束（建议 3–6 分钟，可调）且名册未熄、名册房未彻底失守。
    - 守香失败：名册熄灭，或名册房被占领且无法夺回，或指定关键人物全灭且不能再买人（验收局至少晚倒下且场上无守香司、无香火再买，视为线断，需在结算里写明原因）。
    - 夺名胜利：在天亮前冲进名册房并占领，或抽干名分。
    - 夺名失败：潮被清空且不能再增潮，或天亮未达成目标。
    - 失败必须让人看得出是哪一条线先断。
12. 两边各提供一条可复现的验收开战方式（从菜单或调试进入 `mode=shouxiang` / `mode=duoming`，同一张图、同一模拟器）。

**范围外：**

- 完整夜程图、三选一、夜市循环（P5）。
- 观祭编排和种子复盘（P6）。P4 只要同一模拟器能切两种坐席。
- 20 香器、16 技艺、完整融契表（P7）。
- 32+32 全部进战斗（P8）。
- 标题、暂停菜单美术定稿、失败结算的最终版式（可先用功能完整的简单结算屏，列出失败线和剩余香火/名分）。
- 把框选移动、坚守、撤退做成核心循环。框选只用于夺名批量变异。

## 4. 详细实现规范

### 4.1 守香操作流程

1. 暂停（或在进行中打开面板则自动暂停）。
2. 购入：底部栏或快捷键 Q，列出乡勇 / 弩手 / 更卒（费用 5 / 8 / 6）及本阶段已解锁的具名单位（验收局至少可再购入乡勇、弩手）。卡片必须显示费用、生命、攻击、防御，远程还要显示射程。不够香火的项不可点，要能看出原因。
3. 部署：购入后光标只高亮合法 `CoverPost`。确认后单位出现在该岗位并立刻按职分履职。取消用右键。
4. 点选已有单位，按 E 升级，预览数值差和费用（初稿可与图 15 一致：例如费用 8，生命 +15，防御 +2，必须在 Rules/表里写明，不要写死在按钮贴图里）。
5. 点册：选晚（或技能按钮 R），再选合法鬼。开始读条，朱砂圈占位特效要能在远镜头下认出（完整规格见第 24 号图，P4 至少颜色和形状可辨）。被攻击或目标离开范围则打断。
6. 修门：F，选一扇受损的门，扣香火，门耐久回升。数字初稿写进 Rules。

上场人数建议上限 8 名具名人物 + 少量杂兵，P4 就要有上限，防止无限制买人破掉时间验收。

### 4.2 夺名操作流程

1. 普通潮仍自动推进，玩家不必指挥每一只白衣走路。
2. 变异：框选或点选合格白衣，选「上梁」（12 香火变为缢鬼）或「破门」（15 香火变为力士尸）。同一只单位一夜（本场）不要连变三次，P4 先限制每只最多变一次或两次，并在报告写明。
3. 增潮：花香火在潮源或阴缝再放出一批白衣，有间隔。不得无冷却无限刷到清屏。
4. 玩家没有「把潮拉出去排队」之外的微操责任；若要点选查看，点击即暂停出面板。

### 4.3 同一模拟器

两套指令只是坐席不同的输入层，底下仍是 P2/P3 的单位、公式、门和潮。禁止为夺名复制一份伤害计算。观祭入口可先不做。切坐席在开战前选择，一场内默认不换边（观祭的中途介入是 P6）。

### 4.4 HUD

顶栏：倒计时或目标说明、科仪名（可先写例夜安香）、香火、名分、门状态、上层/二楼状态。底栏：当前坐席可用的指令按钮。警告贴边角。小地图保持 P0 规则。名分将熄、门将破必须看得见。
