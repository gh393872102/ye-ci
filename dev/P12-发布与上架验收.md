# P12. 发布与上架验收

**对应门槛：** 本阶段通过后，即为 **G3 可上架**。  
**前置：** P11 通过。这是发行前的总验收，不是再设计一款游戏。

---

## 1. 本阶段目标

打出稳定的 Windows 可执行文件，键鼠完整、手柄能打完例夜，1080p 60 帧目标在约定场景下达标，设置、存档、种子、最低无障碍项可用。例夜、凶夜、无册夜可玩，三条结局可到达。没有内购、没有强制联网、没有账号永久攻击或生命。发行所需的说明文字和截图按第 13、24、25 号图的标准来，不得用已作废的近景或站位错误图作为商店主图。

## 2. 范围内

1. 导出预置：Windows（Steam 首发必须）。如顺便出 Linux / macOS 可写在报告里，但不替代 Windows。启动不依赖本机安装 Godot。
2. 安装与首次启动：能进标题，能开始例夜，能读设置。崩溃要有日志路径说明。
3. 设置：分辨率与窗口、音量、键位、手柄、边缘滚动、语言（简体中文）。设置可保存。
4. 存档：一夜中途、结夜后的解锁（只开门，不加永久攻防）。可删除存档。
5. 种子可复制、可在观祭输入。无强制联网；若有更新检查必须可关，且离线可玩。
6. 最低无障碍：再开一次「暂停做决策」的提示可关；色弱方面失败线不只靠颜色（门裂纹、名册火苗、文字同时存在）；闪烁特效可降。
7. 性能验收清单：1080p，例夜常规战斗 ≥ 60 帧或平均接近并从不卡输入；高潮 80–150 允许特效降档，输入和暂停不得卡死。记录机器配置。
8. 完整回归：G0 六条、G1 四条、G2 三条、本阶段 G3 三条。把第 21 章禁令再勾一遍。
9. 发行材料：简体中文介绍（一句话 + 一段话 + 特性列表，不泄露未做内容）、3–6 张符合当前镜头和站位标准的截图、支持说明（键鼠手柄、中文）。不要把过程稿 01、12 或院心站人的旧图拿去当主图。
10. 已知问题列表：上架前必须清空关键项；剩余问题按严重度列出。
