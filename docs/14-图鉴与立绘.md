## 14. 图鉴与立绘

这是「游戏是 2D 像素，但点一下要看到精致立绘」的正式落点。

### 14.1 战场点击

- 单击单位：弹出面板。若在实时中点击，自动暂停。
- 面板结构固定，且必须信息完整，不能只放立绘和名字。左或中为精绘立绘，右为：姓名、职分、定位；生命、攻击、防御、速度；专属技能（含香火消耗与一行效果）；特性；今夜已装备的香器/技艺/名帖（含空槽）；阵营标签。可变异或可超度只作为提示，不代替上述数值。标准见图 [17-UI-立绘面板.jpg](../art/17-UI-立绘面板.jpg)、[20-UI-图鉴.jpg](../art/20-UI-图鉴.jpg)。
- 立绘要经得住近看，制作规格高于战场像素单位：成人向灵异，面可以不完整，光要像祠里的冷光，衣饰和持物要看得出职分，不做偶像团海报，不做三头身萌化。
- 夺面、抹名、借脸会改立绘状态（裂面、无面、叠脸），这是主题演出，不是 UI 故障。

### 14.2 图鉴分册

图鉴含四册：**人物、鬼物、香器、风俗**（科仪与关卡块的规则说明）。选中条目后，右侧必须和点击面板同一套信息：数值、技能、特性、装备，见 [20-UI-图鉴.jpg](../art/20-UI-图鉴.jpg)。

解锁过程：

1. 未遭遇：剪影。
2. 首次入场或首次被看见：解锁名与立绘线稿。
3. 首次超度、击破、招募或融契成功：解锁完成色立绘与完整技能文本。
4. 部分条目有「列名」余文，需要特定科仪或结局倾向才会出现，作为收集深度，不挡 1.0 主线。

失败的一夜也要登记「是谁抹掉了你」。图鉴不是胜利者的陈列柜。

### 14.3 制作标准

- 32+32 张精绘立绘是 1.0 必须项，不能用像素放大冒充。
- 香器可用器物图，不必做人像。
- 立绘只出现在面板、图鉴、结夜回顾和偶尔的技能切开（例如夺面的一瞬间），不作为战场背景海报。这是为了保住实机感。
